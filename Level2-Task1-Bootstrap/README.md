
🎒 StudyNest – Student Essentials (Bootstrap Website)

📌 Project Overview

StudyNest is a modern and responsive Bootstrap website designed for students. It showcases the essential items every student needs in a creative and interactive way. The project demonstrates the use of Bootstrap components, responsive layouts, cards, forms, and custom styling.

🚀 Features

- 📱 Fully Responsive Bootstrap Design
- 🎒 Interactive Backpack Explorer
- 💻 Student Essentials Cards
- 📚 Daily Study Routine Section
- ⭐ Student Testimonials
- 📩 Contact Form
- 👣 Professional Footer
- 🎨 Modern UI with Smooth Hover Effects

🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
- Google Fonts
